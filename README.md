# 15 - 行列 行列式 計算 ツール

**slug**: matrix-determinant-calculator
**category**: practical
**build-date**: 2026-11-02

## 概要

2×2・3×3 行列の行列式・逆行列・行列積・転置を計算する。計算手順（サラスの公式・余因子展開）をステップごとに表示する。

## 機能

- 2×2 / 3×3 切替
- 行列式（サラスの公式 / 余因子展開のステップ表示）
- 逆行列（特異行列の検出付き）
- 行列積（A × B）
- 転置行列
- 特異行列（det=0）の警告

## 技術仕様

- 純粋な JS 数値計算
- 全 JS インライン
